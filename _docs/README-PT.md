# King Me! (1998)

[[🇺🇸EN](https://github.com/stefrny/PI_PrefeitoDeLondres/#king-me-1998) | 🇧🇷PT]

Este repositório contém o terceiro projeto de integração do Senac, um cliente para um servidor customizado do jogo de tabuleiro **King Me! (1998)**. O objetivo é aprimorar o raciocínio lógico e as habilidades de programação em geral através do desenvolvimento de um sistema autônomo.

**King Me! (1998)** é um jogo de tabuleiro em que os jogadores se revezam posicionando personagens em no tabuleiro. Assim que todos os personagens estiverem posicionados, cada jogador escolhe um para promover. A rodada termina quando um personagem é coroado rei com a aprovação unânime dos jogadores. O jogo acaba depois de três rodadas e o vencedor é o aquele cujos personagens terminaram nos níveis mais altos.

Apesar do objetivo principal ser a construção de um sistema autônomo, também desenvolvemos uma versão manual do jogo, disponível na branch `jogo-manual`.

Confira o [one sheet paper](https://github.com/stefrny/PI_PrefeitoDeLondres/blob/master/_docs/one-sheet-paper.pdf) com uma apresentação concisa e formal do sistema.

Este projeto depende de um servidor que **não está sob nosso controle**, portanto **não garantimos** que ele funcione corretamente. Ainda assim, o repositório é um excelente material de estudo.
