# King Me! (1998)

[🇺🇸EN | [🇧🇷PT](https://github.com/stefrny/PI_PrefeitoDeLondres/blob/master/_docs/README-PT.md)]

This repository contains the Senac's third integrative project, a client for a custom server version of the board game **King Me! (1998)**. The goal is to further enhance logical thinking and programming skills in general through the development of an autonomous system.

**King Me! (1998)** is a board game in which players take turns placing characters on a grid. After all characters are placed, each player chooses one to promote. A round ends when a character is crowned king and all players agree. The game ends after three rounds, and the winner is the player whose characters reached the hightest levels.

Although the main objective was to build an autonomous system, we also built a manual version of the game, which is available in the `jogo-manual` branch.

Check out the [one sheet paper](https://github.com/stefrny/PI_PrefeitoDeLondres/blob/master/_docs/one-sheet-paper.pdf) for a concise and formal presentation of the system.
